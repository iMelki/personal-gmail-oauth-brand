Milky Local Agent Gmail

This is a personal, single-operator desktop automation that runs on the operator's own Windows PC. It uses Google's Gmail API with read-only access so local tools can search and inspect mail in Google accounts the operator already controls.

It is not a public product, marketplace app, or multi-tenant service. There is no website login. Consent happens in Google's OAuth screen on the operator's machine. The automation does not send mail as part of the Gmail read rollout.
